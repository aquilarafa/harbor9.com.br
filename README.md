# harbor9.com.br

O site da harbor9. É um App do [vertebral](https://vertebral.harbor9.com.br): o `vertebral.pkl` diz o que ele é (arquivos estáticos em `public/`) e onde fica (harbor9.com.br, com www.harbor9.com.br redirecionando para lá).

Publicar uma mudança: commit e push aqui, depois `vt deploy harbor9 --env production`.
